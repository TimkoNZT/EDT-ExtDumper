# EDT ExtDumper

Плагин для EDT, добавляющий в контекстное меню внешних обработок и отчётов команду **«Генерировать .epf/.erf»** для выборочной генерации в любое время (независимо от включения генерации выгрузок в проекте) и отключающий пакетную генерацию при сборке приложения базового проекта.

⚠️ Для отладки внешних обработок галка «Включать автоматическую генерацию выгрузок» должна быть **включена** — ограничение EDT.

ℹ️ Генерация выгрузки при сохранении файлов обработок продолжает работать как обычно.

## Установка

- **Через GitHub**: Help → Install New Software → Add → `https://timkonzt.github.io/EDT-ExtDumper/`
- **Из ZIP-архива**: Help → Install New Software → Add → Archive → указать `edt_extdumper_<версия>.zip` из [релизов](https://github.com/TimkoNZT/EDT-ExtDumper/releases)
