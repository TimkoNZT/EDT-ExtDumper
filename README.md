# EDT ExtDumper

Плагин для EDT, добавляющий в контекстное меню внешних обработок и отчётов команду **«Генерировать .epf/.erf»** для выборочной генерации в любое время, даже при отключённой настройке проекта «Включать автоматическую генерацию выгрузок».

## Установка

- **Через GitHub**: Help → Install New Software → Add → `https://timkonzt.github.io/EDT-ExtDumper/`
- **Из ZIP-архива**: Help → Install New Software → Add → Archive → указать `edt_extdumper_<версия>.zip` из [релизов](https://github.com/TimkoNZT/EDT-ExtDumper/releases)
